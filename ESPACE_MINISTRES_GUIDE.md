# Guide d'Intégration - Espace Ministres Complet\n\n## Vue d'ensemble\n\nCe guide documente l'implémentation complète de l'**Espace Ministres** pour l'application Ecclesiaste. Cet espace permet aux ministres de recevoir des directives, messages pastoraux et données statistiques directement de leur entité, tandis que les responsables d'entité peuvent gérer et communiquer avec leurs ministres.\n\n---\n\n## 1. Architecture et Modèles de Données\n\n### 1.1 Nouveaux Modèles Hive\n\n#### `EntityDirective` (`lib/models/entity_directive.dart`)\nGère les directives, messages et annonces d'entité.\n\n**Champs principaux :**\n- `id` : Identifiant unique\n- `titre` : Titre de la directive\n- `contenu` : Contenu détaillé\n- `type` : DirectiveType (directive, message, annonce, alerte, formulaire, document)\n- `priorite` : DirectivePriority (basse, normale, haute, urgente)\n- `entiteId` : ID de l'entité source\n- `destinatairesMinistresIds` : Liste des IDs des ministres destinataires\n- `lectureStatus` : Map<ministerId, DirectiveStatus> pour tracker la lecture\n- `isConfidential` : Marque confidentiel\n- `dateExpiration` : Date d'expiration optionnelle\n\n**Méthodes utiles :**\n- `isExpired` : Vérifie si la directive a expiré\n- `lecturesCount` : Nombre de lectures\n- `tauxLecture` : Pourcentage de lectures\n- `marquerCommeLue(ministerId)` : Marque comme lue\n\n#### `MinistryStatistics` (`lib/models/ministry_statistics.dart`)\nStocke les statistiques ministérielles par entité.\n\n**Champs principaux :**\n- Présence : `totalMembres`, `presentsMesure`, `tauxPresence`\n- Participation : `participantsActifs`, `participantsInactifs`\n- Activités : `activitesRealisees`, `activitesPlanifiees`\n- Rapports : `rapportsRemis`, `rapportsEnAttente`\n- Finances : `offrandesFC`, `offrandesUSD`, `budgetAlloue`\n- Croissance : `nouveauxMembres`, `saintScelles`, `confirmations`\n\n**Méthodes utiles :**\n- `tauxComplétionRapports` : Pourcentage de rapports remis\n- `tauxParticipation` : Pourcentage de participation\n- `tauxRealisationActivites` : Pourcentage d'activités réalisées\n- `tauxUtilisationBudget` : Pourcentage d'utilisation du budget\n\n---\n\n## 2. Services\n\n### 2.1 Extensions DatabaseHelper\n\n**Nouvelles méthodes dans `DatabaseHelper` :**\n\n```dart\n// Directives\ngetDirectivesForMinister(String ministerId, {String? entiteId})\n  → Récupère les directives triées par priorité\n\ninsertDirective(Map<String, dynamic> data)\n  → Sauvegarde une nouvelle directive\n\nupdateDirectiveStatus(String directiveId, String ministerId, String status)\n  → Met à jour le statut de lecture\n\ngetUnreadDirectivesCount(String ministerId, {String? entiteId})\n  → Compte les directives non lues\n\n// Statistiques\ngetMinistryStatistics(String ministerId, {String? entiteId})\n  → Récupère toutes les statistiques d'un ministre\n\ngetLatestMinistryStatistics(String ministerId, String entiteId)\n  → Récupère les statistiques les plus récentes\n\ninsertMinistryStatistics(Map<String, dynamic> data)\n  → Sauvegarde les statistiques\n```\n\n### 2.2 MinistryNotificationService\n\n**Fichier :** `lib/services/ministry_notification_service.dart`\n\nGère les notifications et indicateurs visuels.\n\n**Méthodes principales :**\n```dart\ngetUnreadDirectivesCount(String ministerId) → Future<int>\ngetUnreadDocumentsCount(String ministerId) → Future<int>\ngetTotalNotificationsCount(String ministerId) → Future<int>\ngetUrgentDirectives(String ministerId) → Future<List>\ngetExpiringDirectives(String ministerId, {int daysThreshold = 3}) → Future<List>\nmarkDirectiveAsRead(String directiveId, String ministerId) → Future<void>\nmarkDocumentAsAccessed(String documentId, String ministerId) → Future<void>\n```\n\n**Système d'écouteurs :**\n```dart\naddUnreadCountListener(Function listener)\naddDirectiveListener(Function listener)\naddDocumentListener(Function listener)\nnotifyNewDirective(String ministerId, Map directive)\nnotifyNewDocument(String ministerId, Map document)\n```\n\n---\n\n## 3. Composants UI\n\n### 3.1 Dashboard Ministre\n\n**Fichier :** `lib/views/dashboards/dashboard_ministre_page.dart`\n\n**Nouvelles sections intégrées :**\n\n1. **EntityDirectivesSection** (`entity_directives_card.dart`)\n   - Affiche les 3 dernières directives\n   - Badge avec compteur de messages non lus\n   - Bouton \"Voir toutes les directives\"\n   - Actions : Marquer comme lu\n\n2. **MinistryStatisticsCard** (`ministry_statistics_card.dart`)\n   - Grille de statistiques avec indicateurs visuels\n   - Taux de présence, participation, réalisation\n   - Données financières et de croissance\n   - Bouton de rafraîchissement\n\n3. **Badge dynamique** dans la section \"Espace Ministres\"\n   - Affiche le nombre de directives non lues\n   - Couleur rouge si messages non lus\n\n### 3.2 Dashboard Responsable d'Entité\n\n**Fichier :** `lib/views/dashboards/dashboard_responsable_entite_page.dart`\n\n**Nouveaux composants intégrés :**\n\n1. **EntityManagerToolsCard** (`entity_manager_tools.dart`)\n   - Grille de 4 outils :\n     - 📤 Envoyer Directive\n     - 📁 Partager Document\n     - 📊 Voir Statistiques\n     - 👥 Gérer Ministres\n   - Badges de comptage pour actions en attente\n\n2. **EntityStatisticsOverview** (`entity_manager_tools.dart`)\n   - Vue d'ensemble rapide :\n     - Ministres actifs / total\n     - Rapports en attente\n     - Utilisation du budget\n     - Croissance (nouveaux membres)\n\n### 3.3 Widgets de Notifications\n\n**Fichier :** `lib/widgets/dashboard/notification_indicator.dart`\n\n1. **NotificationIndicator**\n   - Indicateur visuel avec badge\n   - Montre le nombre total de notifications\n   - Change de couleur si directives urgentes\n\n2. **UrgentNotificationBanner**\n   - Bannière d'alerte pour directives urgentes\n   - Affiche les 2 premières directives urgentes\n   - Bouton de fermeture\n\n3. **ExpiringNotificationAlert**\n   - Alerte pour directives expirant bientôt (< 3 jours)\n   - Affiche les 2 premières directives\n   - Lien \"Voir toutes les directives\"\n\n---\n\n## 4. Pages de Gestion\n\n### 4.1 SendDirectivePage\n\n**Fichier :** `lib/views/send_directive_page.dart`\n\n**Fonctionnalités :**\n- Formulaire de création de directive\n- Sélection du type et priorité\n- Option confidentiel\n- Sélection des ministres destinataires\n- Validation et sauvegarde\n\n**Champs :**\n- Titre (requis)\n- Contenu (requis)\n- Type : message, directive, annonce, alerte, formulaire, document\n- Priorité : basse, normale, haute, urgente\n- Confidentiel : oui/non\n- Destinataires : liste de ministres\n\n### 4.2 ShareConfidentialDocumentPage\n\n**Fichier :** `lib/views/share_confidential_document_page.dart`\n\n**Fonctionnalités :**\n- Partage de documents sécurisés\n- Sélection des destinataires (ministres et commissions)\n- Date d'expiration optionnelle\n- Catégorisation des documents\n- Suivi d'accès\n\n**Types de documents :**\n- Formulaire\n- Protocole\n- Directive administrative\n- Données financières\n- Données statistiques\n- Rapport confidentiel\n- Autre\n\n---\n\n## 5. Flux de Données\n\n### 5.1 Envoi de Directive (Responsable → Ministres)\n\n```\n1. Responsable ouvre SendDirectivePage\n2. Remplit le formulaire (titre, contenu, type, priorité)\n3. Sélectionne les ministres destinataires\n4. Clique sur \"Envoyer\"\n5. Directive sauvegardée dans Hive avec lectureStatus vide\n6. MinistryNotificationService notifie les ministres\n7. Dashboard Ministre affiche la nouvelle directive\n8. Badge du ministre se met à jour\n```\n\n### 5.2 Lecture de Directive (Ministre)\n\n```\n1. Ministre voit la directive dans EntityDirectivesSection\n2. Clique sur la directive ou \"Marquer comme lu\"\n3. DatabaseHelper.updateDirectiveStatus() est appelé\n4. lectureStatus[ministerId] = 'lu'\n5. Badge se met à jour (compteur diminue)\n6. MinistryNotificationService notifie du changement\n```\n\n### 5.3 Partage de Document (Responsable → Ministres)\n\n```\n1. Responsable ouvre ShareConfidentialDocumentPage\n2. Remplit les détails du document\n3. Sélectionne les destinataires\n4. Définit une date d'expiration (optionnel)\n5. Clique sur \"Partager\"\n6. Document sauvegardé avec is_confidential=true\n7. MinistryNotificationService notifie les ministres\n8. Accès au document est tracé dans acces_log\n```\n\n---\n\n## 6.
