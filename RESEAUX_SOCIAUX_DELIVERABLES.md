Services d'Intégration (3 fichiers)\n\n#### `lib/services/youtube_integration_service.dart` (320 lignes)\n**Responsabilité** : Gestion complète de l'intégration YouTube\n\n**Fonctionnalités** :\n- Récupération des vidéos de la chaîne\n- Récupération des statistiques (vues, likes, commentaires)\n- Suivi des vues et engagements\n- Parsing des durées ISO 8601\n- Formatage des nombres (M, K)\n\n**Classes** :\n- `YouTubeIntegrationService` : Service principal\n- `YouTubeVideo` : Modèle pour une vidéo\n- `YouTubeVideoStats` : Statistiques d'une vidéo\n- `YouTubeChannelStats` : Statistiques de la chaîne\n\n**Configuration requise** :\n```dart\nstatic const String CHANNEL_ID = 'UCEcclesiasteKSO';\nstatic const String API_KEY = 'YOUR_YOUTUBE_API_KEY';\n```\n\n---\n\n#### `lib/services/facebook_integration_service.dart` (350 lignes)\n**Responsabilité** : Gestion complète de l'intégration Facebook\n\n**Fonctionnalités** :\n- Authentification avec Facebook\n- Récupération des publications de la page\n- Récupération des statistiques (likes, commentaires, partages)\n- Partage de liens\n- Suivi des engagements\n\n**Classes** :\n- `FacebookIntegrationService` : Service principal\n- `FacebookUser` : Modèle utilisateur\n- `FacebookPost` : Modèle publication\n- `FacebookPostStats` : Statistiques publication\n- `FacebookPageStats` : Statistiques page\n\n**Configuration requise** :\n```dart\nstatic const String APP_ID = 'YOUR_FACEBOOK_APP_ID';\nstatic const String PAGE_ID = 'YOUR_FACEBOOK_PAGE_ID';\n```\n\n---\n\n#### `lib/services/social_media_aggregator_service.dart` (380 lignes)\n**Responsabilité** : Agrégation centralisée de toutes les données sociales\n\n**Fonctionnalités** :\n- Combine YouTube et Facebook\n- Récupère un résumé global des statistiques\n- Fusionne les contenus de tous les réseaux\n- Suivi unifié des interactions\n- Calcul des statistiques globales\n\n**Classes** :\n- `SocialMediaAggregatorService` : Service principal\n- `SocialMediaSummary` : Résumé des statistiques\n- `AggregatedContent` : Contenu fusionné\n- `SocialContent` : Contenu générique\n\n**Utilisation** :\n```dart\nfinal aggregator = SocialMediaAggregatorService();\nawait aggregator.initialize();\nfinal summary = await aggregator.getSocialMediaSummary();\nfinal content = await aggregator.getRecentContent(limit: 20);\n```\n\n---\n\n### 2. Service de Tracking (1 fichier)\n\n#### `lib/services/social_interaction_tracker_service.dart` (420 lignes)\n**Responsabilité** : Enregistrement local et synchronisation des interactions\n\n**Fonctionnalités** :\n- Enregistrement des interactions utilisateur\n- Mise à jour des statistiques d'engagement\n- Suivi des utilisateurs actifs\n- Gestion de la synchronisation serveur\n- Statistiques globales\n\n**Méthodes principales** :\n- `trackInteraction()` : Enregistre une interaction\n- `getUnsyncedInteractions()` : Récupère les interactions non synchronisées\n- `markInteractionAsSynced()` : Marque comme synchronisée\n- `getGlobalStats()` : Statistiques globales\n- `getActiveUsers()` : Utilisateurs actifs\n\n**Utilisation** :\n```dart\nfinal tracker = SocialInteractionTrackerService();\nawait tracker.initialize();\nawait tracker.trackInteraction(\n  userId: user.id,\n  contentId: videoId,\n  platform: 'youtube',\n  contentType: 'video',\n  action: 'view',\n);\n```\n\n---\n\n### 3. Modèles de Données (1 fichier)\n\n#### `lib/models/social_interaction.dart` (280 lignes)\n**Responsabilité** : Modèles Hive pour le stockage local\n\n**Modèles** :\n- `SocialInteraction` : Enregistrement d'une interaction\n- `EngagementStats` : Statistiques d'engagement\n- `ActiveUser` : Profil utilisateur actif\n\n**Champs clés** :\n- Interaction : id, userId, contentId, platform, action, timestamp\n- Stats : viewCount, likeCount, localViewCount, engagementRate\n- User : totalInteractions, favoriteContentIds, actionCounts\n\n---\n\n### 4. Flux 1 : Affichage des Contenus\n\n```\nUtilisateur ouvre Hub Réseaux\n    ↓\nHubReseauxPage._loadData()\n    ↓\nSocialMediaAggregatorService.getRecentContent()\n    ↓\nYouTubeIntegrationService.getChannelVideos()\nFacebookIntegrationService.getPagePosts()\n    ↓\nAggregatedContent avec tous les contenus\n    ↓\nAffichage dans les 3 onglets\n```\n\n### Flux 2 : Tracking des Interactions\n\n```\nUtilisateur regarde vidéo/publication\n    ↓\nYouTubeVideoCard/FacebookPostCard.initState()\n    ↓\n_trackView() appelé automatiquement\n    ↓\nSocialInteractionTrackerService.trackInteraction()\n    ↓\nEnregistrement dans Hive\n    ↓\nMise à jour EngagementStats\nMise à jour ActiveUser\n    ↓\nPrêt pour synchronisation serveur\n```\n\n### Flux 3 : Synchronisation Serveur\n\n```\nSocialInteractionTrackerService.getUnsyncedInteractions()\n    ↓\nEnvoyer interactions vers backend Ecclesiaste\n    ↓\nBackend synchronise avec YouTube/Facebook APIs\n    ↓\nMarkInteractionAsSynced()\n    ↓\nClearSyncedInteractions()\n```\n\n---\n\n## 🚀 Étapes d'Intégration\n\n### Phase 1 : Configuration des APIs\n\n1. ✅ Créer un projet
